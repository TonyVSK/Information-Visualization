Cada linha representa a observação de um país em um ano (1952–2007, em intervalos de cinco anos); há 1.704 casos e seis variáveis. pais é nominal (N), continente é nominal (N), ano é ordinal temporal (Otemp), e expectativa_vida (anos), populacao (habitantes) e pib_per_capita (dólares internacionais ajustados) são quantitativas (Q). A chave composta pais + ano determina as três medidas quantitativas: pais, ano → expectativa_vida, populacao, pib_per_capita; cada país também determina seu continente: pais → continente. pais sozinho não determina as medidas porque há observações repetidas do mesmo país ao longo do tempo.

3. Gráficos

3.1 Gráfico 1 — População e expectativa de vida em 2007

dados |>
  filter(ano == 2007) |>
  ggplot(aes(x = populacao, y = expectativa_vida, colour = continente)) +
  geom_point(alpha = 0.8, size = 2.5) +
  scale_x_log10(labels = scales::label_number()) +
  scale_colour_brewer(palette = "Dark2") +
  labs(title = "População e expectativa de vida por país (2007)",
       x = "População (habitantes, escala log10)", y = "Expectativa de vida (anos)",
       colour = "Continente", caption = "Fonte: Gapminder (dados/gapminder/gapminder.csv)")

Tabela de mapeamento

Variável Tipo (N / O / Otemp / Q / Qtemp) Propriedade gráfica ou espacial
populacao Q posição horizontal (x), escala logarítmica
expectativa_vida Q posição vertical (y)
continente N matiz (cor), escala discreta

Justificativa: A posição em x e y usa duas variáveis quantitativas, mapeamento expressivo para investigar associação entre população e expectativa de vida. A população tem amplitude muito grande, por isso a escala logarítmica em x distribui melhor os países sem alterar sua ordem. O continente é nominal e recebe cores distintas, com paleta discreta; não se sugere uma ordem entre categorias. Pontos são marcas adequadas para observações individuais.

3.2 Gráfico 2 — Expectativa média por continente

dados |>
  filter(ano == 2007) |>
  group_by(continente) |>
  summarise(media_vida = mean(expectativa_vida), .groups = "drop") |>
  ggplot(aes(x = continente, y = media_vida)) +
  geom_col(fill = "#2878A5", width = 0.72) +
  labs(title = "Expectativa média de vida por continente (2007)",
       x = "Continente", y = "Expectativa média de vida (anos)",
       caption = "Fonte: Gapminder (dados/gapminder/gapminder.csv)")

Tabela de mapeamento

Variável Tipo (N / O / Otemp / Q / Qtemp) Propriedade gráfica ou espacial
continente N posição horizontal (x), categorias discretas
media_vida (derivada) Q posição vertical (y), comprimento da barra

Justificativa: A média é quantitativa e seu comprimento em uma barra alinhada a uma base comum permite comparar valores com precisão, uma propriedade efetiva para magnitudes. O continente é nominal, portanto ocupa posições categóricas separadas, sem ordenação numérica implícita. A cor única evita acrescentar uma codificação redundante que não representa uma variável adicional.

Tabela de mapeamento

Variável Tipo (N / O / Otemp / Q / Qtemp) Propriedade gráfica ou espacial
expectativa_vida Q posição horizontal agrupada em intervalos; contagem determina a altura

Justificativa: O histograma usa intervalos contíguos para uma variável quantitativa e mostra a forma da distribuição entre países. A posição horizontal preserva a ordem e a proximidade dos valores; a altura representa a contagem de países em cada intervalo. Intervalos de cinco anos dão uma visão geral legível sem codificações de cor desnecessárias.

4. Makeover

Escolhi o gráfico ruim_05.png, que codifica continentes como números inteiros e usa uma escala contínua de cor.

Diagnóstico: O gráfico atribui números à variável nominal continente e mapeia esses códigos em uma escala contínua de cor, afirmando uma ordem e distâncias entre continentes que a tabela não contém.

dados_makeover <- read_csv("dados/graficos_ruins/gapminder_2007.csv", show_col_types = FALSE) |>
  mutate(continente = factor(continente,
    levels = c("Africa", "Americas", "Asia", "Europe", "Oceania")))

refeito <- ggplot(dados_makeover,
                  aes(x = pib_per_capita, y = expectativa_vida, colour = continente)) +
  geom_point(alpha = 0.75, size = 2.5) +
  scale_x_log10(labels = scales::label_dollar()) +
  scale_colour_brewer(palette = "Dark2", drop = FALSE) +
  labs(title = "Renda e expectativa de vida por país (2007)",
       x = "PIB per capita (dólares internacionais, escala log10)",
       y = "Expectativa de vida (anos)", colour = "Continente",
       caption = "Fonte: Gapminder (dados/graficos_ruins/gapminder_2007.csv)") +
  theme_minimal()

refeito

O que foi corrigido:

  1. continente é convertido em fator e mapeado a uma escala discreta de matizes. Isso respeita seu tipo nominal e remove a falsa ordem que uma escala contínua sugere (expressividade).
  2. Os pontos ficam parcialmente transparentes (alpha = 0.75), reduzindo a obstrução quando países se sobrepõem e permitindo perceber concentrações sem trocar a marca de ponto (efetividade). O rótulo do eixo também explicita a unidade monetária e a escala logarítmica.
